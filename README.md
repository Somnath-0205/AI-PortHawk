# 🛡️ AI-PortHawk

> AI-Powered Network Security Scanner and Threat Assessment Platform

AI-PortHawk is a full-stack cybersecurity application that performs intelligent network reconnaissance, port scanning, service detection, vulnerability assessment, and AI-assisted threat analysis through a modern web dashboard.

---

## ✨ Features

- 🚀 Multi-threaded Port Scanning
- 🌐 Host Discovery
- 🔍 Service Detection
- 📡 Banner Grabbing
- 🖥️ Technology Fingerprinting
- 🔐 TLS/SSL Inspection
- ☁️ Cloud Detection
- 🐳 Docker Detection
- ☸️ Kubernetes Detection
- 🗂️ SMB Enumeration
- 🛡️ CVE Lookup
- 🤖 AI Threat Analysis
- 📊 Real-Time Dashboard
- 📄 PDF Report Generation

```

npm start
```
